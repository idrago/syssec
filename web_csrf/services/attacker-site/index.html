Target API Selection

Choose which API to attack. The teacher must be logged into the matching API in the Teacher Portal for the cookie to be valid.

Attack 1 — Hidden Form (classic CSRF)

Creates a hidden <form> that POSTs to the API with Content-Type: application/x-www-form-urlencoded.
This is a "simple" request — the browser sends it without a CORS preflight and attaches cookies automatically.

Payload: Change Alice's CS101 grade to F.

Attack 2 — fetch() with JSON body

Uses fetch() with Content-Type: application/json and credentials: 'include'.
Because JSON is not a "simple" content type, the browser sends an OPTIONS preflight first to check CORS headers.

Payload: Change Bob's CS101 grade to A+.

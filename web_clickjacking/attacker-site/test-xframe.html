Testing X-Frame-Options Protection

Attempting to load protected site (port 8082) with X-Frame-Options: DENY

Attack Attempt:

Trying to load the protected bank site in an iframe...

Expected Result: The iframe should be blocked by the browser. Open your browser's Developer Console (F12) to see the security error message.
Expected Console Error:
Refused to display 'http://localhost:8082/' in a frame because it set 'X-Frame-Options' to 'deny'.

How X-Frame-Options Works:

  • DENY: Page cannot be displayed in a frame, regardless of the site
  • SAMEORIGIN: Page can only be displayed in a frame on the same origin

Response Header:

X-Frame-Options: DENY

Testing Instructions:

  1. Open Browser DevTools (F12)
  2. Go to the Console tab
  3. Look for the X-Frame-Options violation error
  4. Go to the Network tab
  5. Find the request to localhost:8082
  6. Check the Response Headers - you should see X-Frame-Options: DENY
